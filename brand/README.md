# VELRUNE — Volt Cut

A bold personal portfolio identity: decisive typography, an angular V, and one high-energy accent.

## Files
- `logos/`: transparent SVG symbols, outlined wordmarks, and horizontal lockups in ink, paper, and lime. Wordmarks contain paths and need no installed font.
- `social/`: square avatar SVGs and PNGs.
- `web/`: simplified small-size favicon and reusable brand CSS.
- `fonts/`: self-hostable Space Grotesk variable font, weights 300–700, and the original SIL Open Font License.
- `index.html`: local brand guide. Open it in a browser.

## Palette
Ink #121212 · Warm paper #F3F0E8 · Acid lime #D7FF3F.
Use ink/paper for roughly 90% of a page; reserve lime for focal points and actions. Use ink text on lime; avoid lime text on paper. Ink/paper contrast is 16.45:1 and ink/lime 16.29:1.

## Typography
Space Grotesk 700 for headlines, 400–500 for body. Start body at 16–18px, line height 1.5, maximum line length 65 characters. Large headlines may use -0.04em letter spacing; body copy should use normal spacing.

## Logo rules
Keep clear space of at least one quarter of the symbol width. Recommended minimum wordmark width: 150px; full symbol: 32px. Below 32px use the simplified favicon. Keep original proportions. Use a single colour on busy imagery with a solid contrasting backing. Do not add shadows, gradients, outlines, or stretch the mark. The final SVG wordmark is a clean outlined interpretation of the selected concept, not an exact trace of the AI-generated lettering.

## Website integration
Copy `fonts/`, `web/brand.css`, and chosen logos while preserving relative paths, or adjust CSS font URLs. Link the CSS and add `<link rel="icon" href="/brand/web/favicon.svg" type="image/svg+xml">`. Use an image alt of `Velrune` for the logo; decorative repeated marks should have empty alt text.

## Voice
Direct, curious, personal. Suggested hero: “Selected work. Unfiltered.” Use real project titles and descriptions; avoid invented client or achievement claims.

## Licence
Space Grotesk is free for personal and commercial website use under SIL OFL 1.1. Self-hosting is allowed. Keep `fonts/OFL.txt` when redistributing the font. Logos are delivered as design assets; trademark availability has not been researched.
